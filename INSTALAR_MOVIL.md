# Instalar Rodillo IRONMAN en el móvil

## 1. Publicarla (una sola vez, desde el ordenador)
1. github.com → inicia sesión → **New repository** → nombre `rodillo-ironman` → **Public** → Create.
2. **uploading an existing file** → arrastra TODO el contenido de esta carpeta (no la carpeta en sí:
   que `index.html` quede en la raíz) → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, carpeta `/ (root)` → Save.
4. En 1-2 minutos aparece arriba la URL: `https://TU-USUARIO.github.io/rodillo-ironman/`.

## 2. Instalarla en el móvil
### Android (recomendado)
1. Abre la URL en **Chrome**.
2. Menú ⋮ → **Instalar aplicación** (o "Añadir a pantalla de inicio" → Instalar).
3. Aparece el icono "Rodillo" como una app más. Ábrela desde ahí.
4. La primera vez: activa Bluetooth y Ubicación, y acepta el permiso de "Dispositivos cercanos".

### iPhone
Safari y Chrome de iPhone **no tienen Bluetooth web** → la app no puede hablar con el rodillo.
Opción: instala el navegador gratuito **Bluefy** (App Store), abre la URL dentro de Bluefy y
guárdala en favoritos. Funciona, pero no queda como icono de app instalada.

## 3. Primera sesión
1. Rodillo enchufado y **cerrada la app de Elite** (si está conectada, bloquea el rodillo).
2. Reloj Garmin: **Emitir FC** activado.
3. En la app: **🚴 Rodillo** → elige el Direto → **❤️ FC** → elige el reloj → **Empezar** un entreno.
4. Al acabar: **Exportar CSV**.

## Actualizaciones
Cuando se suben archivos nuevos al repo, la app se actualiza sola al abrirla con internet.
Funciona también sin conexión una vez abierta una vez.
